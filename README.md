# KCCA Vendor Management System

A Java Swing application for managing vendors and stalls.

## Features
- Vendor registration
- Stall allocation
- Role-based login (Admin, Manager, Vendor)

## Technologies
- Java
- Swing GUI

## How to run
1. Compile:
   javac VendorManagementSystem.java
2. Run:
   java VendorManagementSystem
